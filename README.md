# موقع وَنَس

موقع Next.js متصل بنفس Supabase بتاع الداشبورد — أي منتج/فئة/منطقة شحن تضيفيها من الداشبورد بتظهر هنا على طول.

## التشغيل محلياً

1. تأكدي إن عندك Node.js (نسخة 18 أو أحدث)
2. في فولدر المشروع:
   ```
   npm install
   npm run dev
   ```
3. هيفتحلك على `http://localhost:3000`

## الإعداد

انسخي `.env.example` وسميه `.env.local`، واملي فيه:

- `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY` — نفس بيانات Supabase اللي استخدمتيها في الداشبورد
- `NEXT_PUBLIC_WHATSAPP_NUMBER` — رقم الواتساب بتاعك (بصيغة دولية، مثال: 201068759246)
- `NEXT_PUBLIC_VODAFONE_CASH_NUMBER` و `NEXT_PUBLIC_INSTAPAY_HANDLE` — بيانات الدفع اللي هتظهر للعميل وقت اختيار طريقة الدفع

## الصفحات المتاحة

- `/` — الصفحة الرئيسية (Hero، الفئات، ليه وَنَس، الأكتر مبيعًا)
- `/products` — كل المنتجات، مع فلترة حسب الفئة (`/products?category=...`)
- `/products/[slug]` — صفحة تفاصيل المنتج مع معرض الصور
- `/cart` — السلة
- `/checkout` — إتمام الطلب (بيانات العميل، منطقة الشحن، طريقة الدفع)

## اللغة

فيه زرار AR/EN في الهيدر، بيبدل كل النصوص وكمان اتجاه الصفحة (RTL/LTR). أسماء المنتجات والفئات بتتغير تلقائي حسب اللغة (بيقرا من `name_ar`/`name_en` في الداتابيز).

## السلة

بتتخزن في المتصفح (localStorage)، يعني بتفضل موجودة لو العميل قفل المتصفح ورجع تاني، لكن مش متزامنة بين الأجهزة.

## اللي محتاجين نضيفه بعدين

- ربط صفحة الأوردرات في الداشبورد بعرض الطلبات الحقيقية اللي بتيجي من هنا
- صفحة "من نحن" لو عايزة
- تحسين SEO (meta tags لكل صفحة منتج)
